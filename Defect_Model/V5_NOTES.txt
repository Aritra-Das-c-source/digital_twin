V5 CHANGES

1. Keeps the exact same 30 feature names from feature_schema.py.
2. Sensor readings are assigned to the actual unit using
   PROCESSING_STARTED -> PROCESSING_COMPLETED intervals at the same station.
3. Sensor history/recent statistics use only completed upstream intervals
   belonging to the current unit and strictly available before prediction time.
4. Recent window remains exactly [prediction_time - 600000, prediction_time).
5. queue_history_mean/std are now unit-specific, using the current unit's
   previous UNIT_ARRIVED queue observations.
6. Manual, cycle, metadata, target logic, and 30-feature contract are preserved.
7. V5 training is the V4 training pipeline copied to generated_features_v5/
   with V5 output/model names.
8. The old consumed test split is not accessed.
