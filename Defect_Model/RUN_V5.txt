V5 FEATURE FIX - RUN COMMANDS

Place these files into your existing project.

Required existing dependency:
src/train_catboost_v3.py

Then run from the project root:

python -m py_compile src/build_causal_features_v5.py
python -m py_compile src/train_catboost_v5.py

python src/build_causal_features_v5.py --workers 4

Only if feature generation completes successfully:

python src/train_catboost_v5.py

Outputs:
generated_features_v5/train.pkl
generated_features_v5/validation.pkl
results/v5_*.csv / v5_*.json
saved_models/defect_v5_*.joblib / defect_v5_config.json

The old generated_features/, V4 models/results, and test split are not overwritten or accessed.
